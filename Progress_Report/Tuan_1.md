## 1. Nội dung công việc đã thực hiện

- Xác định **lý do chọn đề tài**: Thương mại điện tử đang phát triển mạnh, nhu cầu mua sắm sản phẩm công nghệ Apple (iPhone, MacBook, iPad,...) trực tuyến ngày càng tăng cao; đây là chủ đề thiết thực để áp dụng kiến thức ASP.NET MVC vào dự án thực tế.
- Xác định **mục tiêu đề tài**: Xây dựng website thương mại điện tử hoàn chỉnh gồm giao diện người dùng (mua sắm) và giao diện quản trị (Admin).
- Xác định **đối tượng và phạm vi nghiên cứu**: Người dùng cuối (khách hàng mua hàng trực tuyến) và quản trị viên hệ thống; phạm vi giới hạn trong môi trường web, triển khai trên Localhost.
- Nghiên cứu tổng quan về **framework ASP.NET MVC 5**:
  - Kiến trúc mô hình MVC (Model - View - Controller).
  - Cơ chế Routing, Controller, Action, View Engine (Razor).
  - Vòng đời xử lý HTTP Request trong ASP.NET.
- Tìm hiểu các **công nghệ bổ trợ phía front-end**:
  - HTML5, CSS3: Cấu trúc và định kiểu giao diện.
  - JavaScript và thư viện **jQuery**: Tương tác động phía client.
  - **Bootstrap 3/4**: Thiết kế giao diện responsive, tương thích đa thiết bị.
- Khảo sát và tải về **Template giao diện SB Admin 2** (Bootstrap) để làm nền tảng cho khu vực quản trị.
- Cài đặt và cấu hình môi trường phát triển: Visual Studio, .NET Framework 4.x, SQL Server Management Studio (SSMS).

---

## 2. Tài liệu liên quan đã tham khảo

- Sách chuyên ngành lập trình web ASP.NET MVC.
- Khóa học lập trình **ASP.NET MVC** của TEDU (Tự học IT).
- Tài liệu chính thức của Microsoft: [docs.microsoft.com/aspnet/mvc](https://learn.microsoft.com/en-us/aspnet/mvc/).
- Mã nguồn giao diện **Template Bootstrap SB Admin 2** (StartBootstrap).
- Tài liệu về giao thức HTTP/HTTPS và cơ chế hoạt động của Web Server.

## 3. Khó khăn gặp phải

- **Hệ thống hóa kiến thức MVC**: Gặp khó khăn trong việc phân biệt rõ trách nhiệm của từng thành phần Model, View, Controller; cần đọc lại nhiều tài liệu để hiểu đúng luồng dữ liệu trong ứng dụng.
- **Tích hợp thư viện front-end**: Xác định thứ tự nhúng file CSS/JS (Bootstrap, jQuery, các plugin) vào `_Layout.cshtml` sao cho không xung đột và tối ưu thời gian tải trang.
- **Chuẩn bị môi trường**: Mất thời gian cài đặt và cấu hình Visual Studio cùng .NET Framework đúng phiên bản tương thích với ASP.NET MVC 5.
